# Group 5 Assignment Instructions

These instructions apply to all Codex work in this repository for Group 5's CS F301 Principles of Programming Languages Assignment 2.

## Before starting work

- Before implementing a Prolog task, read `5/skills/prolog-dev/SKILL.md`.
- Before implementing a Scheme task, read `5/skills/scheme-dev/SKILL.md`.
- Treat the assignment PDF as the authoritative specification. Follow its language restrictions and required file paths.
- The group ID is `5`. Use the prescribed Group 5 names for all solution files and directories.

## Prompt logging

- Whenever the user provides a new implementation, testing, or review prompt for a problem, append its exact wording to that problem's prompt file:
  - P1: `5/prompts/P1.md`
  - P2: `5/prompts/P2.md`
  - S1: `5/prompts/S1.md`
  - S2: `5/prompts/S2.md`
- Preserve each prompt verbatim. Do not paraphrase, summarize, or silently correct it. Keep its wording, punctuation, and formatting intact.
- Do not log ordinary conversational messages or clarification questions as task prompts.
- Do not duplicate a prompt that is already logged. Check the corresponding file before appending.
- Create the corresponding prompt file if it does not exist.
- Perform prompt logging automatically; never ask the user to remind you.

## Scope and assignment decomposition

- Strictly follow the assignment's one-unit-per-prompt rule. One prompt may address only one predicate, function, test file, or review.
- Never implement an entire problem in one request.
- Implement only what the latest prompt requests. Do not independently expand its scope.

## Repository care and completion report

- Preserve existing code and Git history. Do not overwrite unrelated work.
- Before finishing a task, report:
  - Files created or modified.
  - What was implemented.
  - Tests performed and their results, or state that no tests were run.
  - Any remaining concerns.
